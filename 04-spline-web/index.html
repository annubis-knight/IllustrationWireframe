Intégration

Un seul tag

Le composant est un élément HTML natif : il fonctionne dans une page nue, dans Nuxt, dans WordPress, sans build ni framework.

<script src="wire-rocket.js"></script>

<wire-rocket
  tier="booster"
  color="#9d8cff"
  label="VITESSE"
  value="7,66 KM/S"
  module="02 / 03"></wire-rocket>

<script>
  // Pilotable depuis l'extérieur
  document.querySelector('wire-rocket').boost = true;
</script>

Le même composant, trois tailles — il s'adapte à son conteneur

Emplacement Spline

Une scène Spline ne se génère pas par code : elle se crée dans l'éditeur, puis s'exporte en URL publique. Colle l'URL de ta scène dans js/demo.js (constante SPLINE_URL) et le visualiseur remplacera ce cadre, pour comparer poids et fluidité avec le composant maison.
